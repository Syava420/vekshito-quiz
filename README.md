# Эрудит Quiz (Вопросы Векшито)

Мобильное веб-приложение для тренировки эрудиции и закрепления школьных знаний по методике мягкого интервального повторения (Relaxed SRS).

Создано на основе базы уличных опросов канала «Векшито» (Биология, Химия, Физика, История, География, Литература, Русский язык, Математика и логика).

---

## 📱 Особенности приложения

1. **Mobile-First UX под смартфон:**
   - Крупные touch-кнопки под большой палец (>48px).
   - Чистый OLED тёмный интерфейс без визуального шума.
   - PWA: работает офлайн, можно добавить на экран смартфона как иконку («На экран "Домой"`).

2. **3 режима ответов (переключаются прямо в шапке в один клик):**
   - **Варианты (4 кнопки):** классический выбор ответа.
   - **Ввод слова:** набор ответа на клавиатуре с умной защитой от опечаток (1 опечатка прощается) и кнопкой-подсказкой первой буквы.
   - **Да / Нет:** быстрая проверка фактов (правда или ложь).

3. **Мягкий SRS (без таймеров и без ежедневного стресса):**
   - Уровень 1: повтор через 1 месяц
   - Уровень 2: повтор через 2 месяца
   - Уровень 3: повтор через 6 месяцев
   - Мастер: повтор через 1 год
   - При ошибке вопрос откатывается всего на 1 шаг назад (повтор через 14 дней).

4. **Фильтры тем:**
   - Можно выбрать любую отдельную категорию (например, только Химию или только Физику) или режим «Все темы (микс)».
   - Переключатель «Только созревшие к повторению».

5. **Безопасность прогресса:**
   - Прогресс сохраняется в браузере (LocalStorage).
   - В настройках доступен экспорт/импорт файла бэкапа в JSON.

6. **База вопросов:**
   - Всего доступно **315 тщательно отобранных вопросов** по 8 категориям (Биология, Химия, Физика, История, География, Литература, Русский язык, Математика и логика).
   - База структурирована по модулям в папке `data/categories/`.

---

## 🚀 Как запустить

### На компьютере:
Запустите локальный сервер:
```bash
node server.js
```
Откройте в браузере: `http://localhost:3000/`

### На телефоне в той же Wi-Fi сети:
Узнайте свой локальный IP-адрес компьютера (например, `192.168.1.45`) и откройте на телефоне:
`http://192.168.1.45:3000/`
В Safari / Chrome нажмите «Поделиться» → «На экран "Домой"».
